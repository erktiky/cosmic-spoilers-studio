Privacy policy

Last updated: 6 October 2026.

Cosmic Spoilers Studio is a private tool used only by the owner of the Cosmic Spoilers YouTube channel. No other users can use it.

What it accesses: with the owner's consent (read-only scopes youtube.readonly and yt-analytics.readonly) it reads the owner's channel information, video list and YouTube Analytics reports.

Where the data goes: the data is stored only on the owner's own computer, for the owner's production dashboard. It is not sold, shared, transferred to third parties or used for advertising. The tool does not access any other person's data.

Google API Services User Data Policy: the tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access: access can be revoked at any time at myaccount.google.com/permissions; locally stored data can be deleted by the owner.
